# Security

Report a vulnerability through GitHub private vulnerability reporting on this repository. Do not open a public issue for a security bug.

That includes kernel bugs in the Windows driver developed under `driver/`. Report those privately as well, even when the driver code lives on another branch.

Please include the version (`Cargo.toml` or the `vX.Y.Z` tag), the operating system, and enough detail to reproduce the problem. You should hear back after the report is reviewed.
